# 🛡️ CloudSentinel Pro: Enterprise Cloud Guardrail
**Global Automated Security Orchestration & Remediation Engine**

Built for the scale of modern financial institutions, **CloudSentinel Pro** is a real-time defense suite that audits, remediates, and visualizes AWS infrastructure security.

## 🚀 Key Features
- **Real-Time Remediation:** Instantly fixes "Configuration Drift" via EventBridge triggers.
- **Global Visibility:** Audits infrastructure across all AWS Regions to eliminate blind spots.
- **Interactive SOC Dashboard:** Lovable, glassmorphism UI for executive-level risk reporting.
- **Threat Intel Mapping:** Categorizes vulnerabilities using **MITRE ATT&CK** techniques.

## 🛠️ Tech Stack
- **Languages:** Python (Boto3, Streamlit, Pandas)
- **Cloud Services:** AWS (Lambda, S3, SNS, EventBridge, IAM, CloudShell)
- **Security Standards:** NIST 800-53 Compliance & Automated Secret Scanning

## 📈 Impact
This project shifts security from manual checklists to automated "Self-Healing" infrastructure, reducing the mean time to remediate (MTTR) critical vulnerabilities from hours to seconds.
